Reference guide

PinThing Help

PinThing is a generative kinetic sculpture—a shape display brought to life through motion. This video simulator turns source frames into eight-height mechanical pin movement. Use this guide as a quick reference for every option and interaction.

Source & playback

Video source
Choose a bundled clip from the dropdown, or use the adjacent upload button to select a local MP4 or WebM. You can also drag a video onto the source section. Fortnite loads by default.
▶Play / pause
Use the play button, click the original video, or press P from anywhere on the page.
Timeline
Drag the red playhead to scrub, rewind, or jump to any available point in the video.
Audio
Use the speaker button to mute or unmute and the adjacent slider to set volume. Playback starts muted so the video can autoplay reliably.
Frame rate
Simulates a display updating at 5, 10, or 15 FPS. Source / original uses the clip’s natural update rate. Limited modes visibly hold both views while the pins travel toward each new target.

Display & image

Display size
Changes the physical pixel matrix.
27″ diagonal45 × 30 px · 1,350 pins 93″ diagonal168 × 87 px · 14,616 pins 157″ diagonal282 × 146 px · 41,172 pins
Color
Applies posterized source-video color to each pin using eight values per RGB channel—up to 512 combined colors. Turn it off for a neutral metallic display driven only by luminance and depth.
Specifications
Each pin is spaced 12.5 mm center-to-center and moves through eight discrete heights over 47 mm of total travel—approximately 6.7 mm between positions.

Dithering

Blue noise
Distributes quantization texture with minimal visible repetition. Often the most natural-looking option for moving imagery.
Floyd–Steinberg
Pushes quantization error into neighboring pins. Preserves gradients and detail, with a more organic diffusion texture.
Clustered dots
Groups thresholds into visible dot-like structures, similar to graphic halftone screening.
Bayer 4×4
Uses a repeating ordered threshold matrix. Produces stable, crisp patterns with little temporal noise.
Off / Hard Threshold
Skips spatial dithering and maps luminance directly to the nearest of the eight physical pin heights.

View controls

Layout
Switches between Stacked and Side by side. In Stacked view, the pin render is on top.
Divider
Drag the divider to resize the two views. Double-click it to restore the default split. When focused, use the arrow keys; hold Shift for larger steps.
Original / Render
The eye buttons independently show or hide the source video and 3D pin render. Render-only is the default view.
Fullscreen
Expands PinThing to the full screen. Use the same button—or your browser’s usual exit gesture—to return.

3D camera & interface

Orbit
Drag on the pin render to rotate around the display. Right-drag to pan and use the mouse wheel or trackpad to zoom.
Reset view
The circular-arrow button returns the camera to its original framing.
Theme
Cycles through Light, Dark, and System. System follows the operating-system appearance setting.
Control panel
The three-dot button opens or collapses the panel. The question-mark button opens this guide.

Zoom mode

What it does
Shows how a physical 45 × 30 display would render a selected portion of a larger virtual display, instead of compressing the entire source frame into 45 × 30 pins.
How to use it
With the 27″ / 45 × 30 display selected, click the magnifying-glass button. Move over the original video to position the highlighted capture area.
Mode cycle
Each click advances through Off → 93″ source grid → 157″ source grid → Off. The yellow overlay identifies the active larger source grid.

URL parameters

v Video
Loads a bundled alias or an MP4/WebM filename from the project folder. ftFortnitebaBad ApplecmLarry Cube - Calculated Movementsmy-loop.webmFilename
view View
Chooses which panes appear and how two visible panes are arranged. Render-only is used when this parameter is omitted. rRender onlyoOriginal onlystStackedsbSide by side
split Divider
Sets the first pane’s percentage when both panes are visible. Values are constrained from 20 to 80. For example, split=60.
color Pin color
Starts the pin render with posterized color enabled or disabled. Use color=on or color=off. Color is on when this parameter is omitted.

Performance note: the larger matrices create many more rendered pins. If interaction becomes sluggish, use the 45 × 30 display while composing the scene, then switch to a larger size for evaluation.
